# Find’Em

A collaborative mobile application designed to help communities locate lost pets through geolocation, real-time data sharing, and direct user interaction.

---

## About the Project

**Find’Em** was created to solve a real-world problem: the difficulty of finding lost pets quickly and efficiently.

The platform allows users to report lost or found animals, explore nearby cases on an interactive map, and connect directly with other users. It also includes an adoption feature designed to support NGOs and individuals in finding homes for rescued animals.

By combining geolocation, cloud services, and community engagement, the app increases the chances of reconnecting pets with their owners.

---

## Features

- Register lost pets with geolocation
- View nearby cases using an interactive map
- Filter search results for better navigation
- “Found Pets” section for animals located by users
- Adoption area with structured form (NGO-friendly)
- Upload and view images
- Community feed of posts
- Favorite and track cases
- Direct contact with owners via WhatsApp integration
- Real-time updates using cloud database
